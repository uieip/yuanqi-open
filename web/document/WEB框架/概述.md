# 二、快速开始

## 1. 克隆项目

```bash
git clone <repository-url>
cd yuanqi.go-vue
```

## 2. 安装前端依赖

```bash
cd webvue
npm install
```

## 3. 配置后端服务

编辑 `svr/config.json` 配置文件，主要配置项：

```json
{
  "websvr": {
    "webtype": "sso",
    "addr": "3010",
    "webpath": "D:\\Spring\\yuanqi.go-vue\\webvue",
    "debug": true
  }
}
```

## 4. 启动后端服务

运行 Go 后端服务：

```bash
cd svr
.\uieip-windows.exe
```

后端服务将在 `http://localhost:8011` 启动。

## 5. 启动前端开发服务器

```bash
cd webvue
npm run dev
```

前端开发服务器将在 `http://localhost:5175` 启动。

## 6. 访问应用

打开浏览器访问:
- **前端开发服务器**: http://localhost:5175
- **后端服务**: http://localhost:8011

## 7. 默认登录信息

- **本地测试地址**: http://127.0.0.1:8011/
- **用户名**: spring
- **密码**: uieip.123

## 1. 自定义路由系统

项目使用自定义 Vite 插件 `vite-plugin-uieip-router` 实现灵活的路由和代理功能。

### 1.1 路由规则

- **特殊字符路由**
  - `_` (下划线): handler 目录程序文件
  - `!` (感叹号): 数据库文件请求
  - `^` (脱字符): 文件柜请求
  - `@` (艾特符号): 文件柜请求
  - `` ` `` (反引号): 程序处理标识符

- **文件扩展名路由**
  - `.html`: HTML 文件，从后端获取并使用 Vite 转换
  - `.json`: JSON 数据，代理到后端

### 1.2 请求代理功能

- **.proxyHandler**

处理所有非 HTML 请求的代理转发：

**功能特性**:

1. **请求头处理**: 复制原始请求的所有 headers（包括 Cookie）
2. **请求数据处理**: 支持 multipart/form-data、application/json 等多种格式
3. **响应头处理**: 自动设置正确的 Content-Type 和字符集
4. **响应数据处理**: 正确处理 Buffer、ArrayBuffer、字符串、对象等数据类型
5. **错误处理**: 提供详细的错误信息

- **.htmlHandler**

处理 HTML 文件请求：

**功能特性**:

1. **从后端获取 HTML**: 请求 `http://localhost:8011` 获取 HTML 内容
2. **请求头传递**: 传递 Cookie 等认证信息
3. **Vite 转换**: 使用 `viteServer.transformIndexHtml()` 处理 HTML
4. **临时文件管理**: 自动创建 temp 目录并保存 HTML
5. **重定向支持**: 禁用自动跟随重定向，获取 Location 头

# 四、备忘
- **日期选择器格式**
  - Element Plus 日期选择器使用 Day.js 的日期格式语法
  - YYYY 表示四位年份， MM 表示两位月份， DD 表示两位日期
  - 使用大写字母可以确保日期格式的正确解析，避免小写字母在某些本地化设置中被错误解析
