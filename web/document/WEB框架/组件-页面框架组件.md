# 一、YqLayout
整体布局组件，集成侧边栏、头部、内容区、底部。

- **属性**
```javascript
const props = withDefaults(defineProps<{
  sidebarWidth?: number         // 侧边栏宽度，默认260
  sidebarCollapsedWidth?: number // 侧边栏折叠宽度，默认64
  headerHeight?: number         // 头部高度，默认55
  logo?: LogoConfig             // logo配置：{ icon, text, path }
  showUserInfo?: boolean        // 是否显示用户信息，默认true
  userInfo?: UserInfo           // 用户信息：{ name, icon, role, admin }
  menuItems?: MenuItem[]        // 侧边栏菜单
  navItems?: MenuItem[]         // 顶部导航菜单
  breadcrumb?: MenuItem[]       // 面包屑数据
  userDropdownItems?: MenuItem[]// 用户下拉菜单
  toolbarItems?: MenuItem[]     // 右侧工具栏
  defaultTabs?: MenuItem[]      // 默认页签列表
  isMultiTab?: boolean          // 是否多页签模式（true 多页签 / false 单页签），默认true
}>(), {
  sidebarWidth: 260,
  sidebarCollapsedWidth: 64,
  headerHeight: 55,
  logo: () => ({ text: '远齐-Yuanqi', icon: 'fa fa-file-code-o', path: '/' }),
  showUserInfo: true,
  userInfo: () => ({ name: 'demo', icon: 'fa fa-user' }),
  menuItems: () => [],
  navItems: () => [],
  breadcrumb: () => [],
  userDropdownItems: () => [],
  toolbarItems: () => [],
  defaultTabs: () => [
    { id: 'dashboard', label: '首页', icon: 'fa fa-file', path: '/', isUrl: true, active: true, closable: false }
  ],
  isMultiTab: true
})
```

# 六、YqTabs
标签页组件，支持图标、多方向（上/下/左/右），可通过 `tabs` 属性传入配置数组，支持 `labelDict` 多语言翻译。

- **属性**
```javascript
const props = withDefaults(defineProps<{
  modelValue?: string             // 当前激活的标签页name
  tabPosition?: 'top' | 'bottom' | 'left' | 'right'  // 标签位置
  tabs?: YqTabConfig[]            // 标签页配置数组
  /** 多语言标签页字典
  格式：
  {
      "zh-CN": {tab1: '标签页1', tab2: '标签页2'},
      "en":    {tab1: 'Tab 1',    tab2: 'Tab 2'}
  }
  */
  labelDict?: Record<string, Record<string, string>>
}>(), {
  modelValue: '',
  tabPosition: 'top',
  tabs: () => []
})
```
YqTabConfig 数据类型
```javascript
export interface YqTabConfig {
  name: string                    // 标签页标识
  label: string                   // 标签文本
  icon?: string | object          // 图标（支持YqIcon所有类型）
  disabled?: boolean              // 是否禁用
  closable?: boolean              // 是否可关闭
  lazy?: boolean                  // 是否延迟渲染
}
```

- **说明**：传入 `labelDict` 后，组件会通过 `provide('yq-tabs-label-dict')` 将按当前语言解析后的 `{ name: label }` 字典下发给默认插槽中的 `YqTabPane`，使子 `YqTabPane` 的标签文本也能按 `name` 翻译。`tabs` 数组中的标签也会优先取 `labelDict[name]`。

- **事件**
```javascript
const emit = defineEmits<{
  'update:modelValue': [value: string];
  'tab-click': [tab: TabsPaneContext];
}>();
```

# 七、YqTabPane
标签面板组件，包装 ElementPlus ElTabPane，支持图标显示。

- **属性**
```javascript
const props = withDefaults(defineProps<{
  label?: string | (() => unknown) // 标签文本（支持函数形式）
  name?: string                    // 标签标识
  disabled?: boolean               // 是否禁用
  closable?: boolean               // 是否可关闭
  lazy?: boolean                   // 是否延迟渲染
  icon?: string | object           // 图标（支持YqIcon所有图标类型）
}>(), {
  label: '',
  name: '',
  disabled: false,
  closable: false,
  lazy: false,
  icon: ''
})
```

- **说明**：组件通过 `inject('yq-tabs-label-dict')` 接收父级 `YqTabs` 提供的多语言字典，渲染时优先取 `labelDict[name]`，未命中则回退到 `label`（支持函数形式）。

# 十、YqButton
按钮组件，包装 ElementPlus ElButton，支持 `labelDict` 多语言翻译。

- **属性**
```javascript
const props = withDefaults(defineProps<{
  /** 按钮文本（labelDict 翻译优先，其次回退插槽内容） */
  label?: string
  /** 多语言按钮文本字典
  格式：{ "zh-CN": "保存设置", "en": "Save Settings" }
  */
  labelDict?: Record<string, string>
}>(), {
  label: '',
})
```

- **说明**：渲染顺序为 `labelDict`（按当前 locale 解析）→ `label` prop → 默认插槽内容。其余按钮行为/样式透传至 `ElButton`。

# 十二、YqLayoutIndex
主窗体布局组件，封装 `YqLayout`，开箱即用。自动处理：
- 登录状态获取（`YqWindowApi.loginStateGet`）
- 应用列表与侧边栏菜单加载（`yqData.dbApps` / `yqData.dbMenus`，配合 `YqMenuUtils.convertToMenuItems` 转换）
- 用户信息、面包屑、工具栏、用户下拉菜单等装配
- 设置弹窗：语言切换（`setLocale`）、多页签模式开关（持久化到 `localStorage`）

- **属性**
```javascript
const props = withDefaults(defineProps<{
  // 组件标签（唯一标识实例，用于多页签缓存键）
  tag?: string
  // 应用编号列表
  appNos?: number[]
  // 默认URL（首页页签的path）
  defaultUrl?: string
  sidebarWidth?: number
  sidebarCollapsedWidth?: number
  headerHeight?: number
  // logo配置
  logo?: LogoConfig
  // 面包屑配置
  breadcrumb?: MenuItem[]
  // 是否显示用户信息
  showUserInfo?: boolean
  // 是否显示"个人中心"入口
  showProfile?: boolean
  // 是否多页签模式  true 多页签模式  false 单页签模式
  isMultiTab?: boolean
}>(), {
  tag: '',
  appNos: () => [0],
  defaultUrl: 'index.html',
  sidebarWidth: 260,
  sidebarCollapsedWidth: 64,
  headerHeight: 55,
  logo: (): LogoConfig => ({}),
  breadcrumb: () => [],
  showUserInfo: true,
  showProfile: true,
  isMultiTab: true,
})
```

- **说明**：
  - 多页签模式缓存键为 `yq-layout-multiTab-<tag>`，未设置时回退到 `props.isMultiTab`。
  - 菜单加载后，会过滤掉 label 为"组件测试"的菜单项。
  - 工具栏内置"刷新"与"全屏"按钮；用户下拉菜单内置"个人中心"（可选）、"设置"、"退出"项。
  - 设置弹窗中切换语言后会调用 `window.location.reload()` 刷新页面。
