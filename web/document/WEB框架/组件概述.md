# 概述
基于ElementPlus组件库开发，用于后台管理端应用。

# 〇、国际化（i18n）
框架内置 vue-i18n 多语言支持，通过 `labelDict` 属性实现组件文本的多语言翻译。

- 语言包：`src/locales/zh-CN.ts`、`src/locales/en.ts`
- API：`setLocale(locale)`、`getLocale()`、`resolveLabelDict(labelDict)`
- 支持 `labelDict` 的组件：YqButton、YqLabel、YqTabs、YqTabPane、YqMenu、YqEditMenu、YqDataGrid、YqCombogrid、YqDataTree、YqMessageBox、YqMessage 等

`labelDict` 格式示例：
```javascript
{
  "zh-CN": { "label": "添加", "toptip": "添加新记录" },
  "en":    { "label": "Add",  "toptip": "Add new record" }
}
```
