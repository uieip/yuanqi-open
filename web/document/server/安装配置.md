***websvr***
- websvr:webtype   服务类型
  - default：默认，应用站点
  - cms：网站
  - sso: 单点登录
- websvr:addr 服务端口号
- websvr:webpath 站点目录，可为 "../website" 或 "D:\\Spring\\yuanqi.go\\website"（相对目录、绝对目录）
- websvr:debug 开发模式
- websvr:timeout 请求过期 单位：毫秒
- websvr:scheme 站点服务类型 http或https
- websvr:host  站点名词
- websvr:cms   站点名称，对管理端“站点名称”
- websvr:zip 输出文件压缩
当(websvr:debug==false && websvr:zip==true)时，输出文件压缩，其它为不压缩。
- websvr:funcpath 后台程序目录
- websvr:proxyurl 后台服务发送消息需要的上网代理地址，如：

```
// TTP 客户端
proxyURL = "http://proxy.example.com:8080"
// 带认证的代理
proxyURL = "http://username:password@proxy.example.com:8080"

proxyURL = "socks5://proxy.example.com:1080"
// 带认证的代理
proxyURL = "socks5://username:password@proxy.example.com:1080"
```
