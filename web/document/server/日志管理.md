# 一、目的
记录用户操作，便于审计、排查问题及追踪责任。
# 二、功能需求
- **记录操作**：用户登录、数据增删改、系统配置变更等。
- **查询日志**：按时间、用户、操作类型等条件查询。
- **日志导出**：支持导出为Excel、CSV等格式。
- **日志清理**：定期清理或归档旧日志。
- **权限控制**：仅授权用户可访问日志。

# 三、消息类型

| 序号 | 名称 | 说明 |
| ------------ | ------------ | ------------ |
| 0 |  DEBUG | 程序调试bug时使用 |
| 1 |  INFO | 程序正常运行时使用，运行消息提示 |
| 5 |  WARNING | 程序未按预期运行时使用，但并不是错误，如:用户登录密码错误 |
| 8 |  ERROR | 程序出错误时使用，如:IO操作失败 |
| 9 |  CRITICAL | 特别严重的问题，导致程序不能再继续运行时使用，如:磁盘空间为空，一般很少使 |
| 10 |  OPERATION | 操作日志，用户登录、用户退出登录、数据增删改、数据查询。 |

- 默认的是WARNING等级，当在WARNING或WARNING之上等级的才记录日志信息。
- 日志等级从低到高的顺序是: DEBUG < INFO < WARNING < ERROR < CRITICAL

# 四、web端【系统监控】
- 界面路径：管理后台=》服务管理=》系统监控
open开启错误
```
websocket: the client is not using the websocket protocol:  'upgrade' token not found in 'Connection' header
```
nginx配置原因：
添加：
```json
    proxy_http_version 1.1;
    proxy_set_header Upgrade $http_upgrade;
    proxy_set_header Connection "upgrade";
```
示例：
```json
upstream sso.uieip.com{
   server 127.0.0.1:8010  weight=1 fail_timeout=5s max_fails=3;
}
server {
  listen 80;
  server_name sso.uieip.com;

  location / {
    proxy_pass http://sso.uieip.com;   #指定upstream分组的名称
    server_name_in_redirect on;
    port_in_redirect off;
    charset utf-8;

    #file size
    client_max_body_size 10240m;
    proxy_request_buffering off;

    #设置主机头和客户端真实地址，以便服务器获取客户端真实IP
    proxy_set_header Host $http_host;        #包含客户端真实的域名和端口号
    proxy_set_header X-Real-IP $remote_addr; #表示客户端真实的IP
    proxy_set_header X-Scheme $scheme;       #传递协议
    proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for; #在多层代理时会包含真实客户端及中间每个代理服务器的IP
    #proxy_set_header   Cookie           $http_cookie;
    #proxy_set_header   Connection       "upgrade";

    proxy_http_version 1.1;
    proxy_set_header Upgrade $http_upgrade;
    proxy_set_header Connection "upgrade";
   }
}
```
