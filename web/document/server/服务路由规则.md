# 服务路由规则

# 一、文件名命名规则

- 1. "\_" handler目录程序文件

  - 格式："\_"{文件名}.html，如\_Dbhandler.html
  - Post、Get程序文件标识

- 2. “!” 文件请求标识符（数据库）

  - 格式：!{0}\_{1}.{2}
  - {0}：数据库，{1}：文件sid，{2}：扩展名
    - 例：!cms\_8db7de84-e639-455f-9a61-239f196f940e.jpg

- 3. “^”，“@” 文件请求标识符（文件柜）

  - 格式： 
    - ^{0}_{1}.{2} 或 @{0}_{1}.{2}
    - {0}：文件柜，{1}：文件sid，{2}：扩展名
    - 例：
      - ^cms\_8db7de84-e639-455f-9a61-239f196f940e.jpg 
      - 或
      - @cms\_8db7de84-e639-455f-9a61-239f196f940e.jpg

- 4. “\`” 程序处理标识符

    - 针对 js、css处理，其他文件类型无效
    - 程序文件位置为站点路径下文件，为js、css这些资源文件，后台程序文件后缀不变。
    - 例如：
      - 请求URL：<http://www.yqsite.com/cn/js/`area.js?ver=1>
      - 后台对应文件为：js/\`area.html

# 二、图片水印

- 仅对以@为标识符的图片文件。
  - 图片水印模版放置路径：网站根目录下，文件名：watermark.png
  - 水印尺寸：图片高度的三分之一，宽度自适应

- 1. 参数

  - w:宽带
  - h:高度
  - t:缩放格式
  - \=a:指定高宽缩放（可能变形）
  - \=w:指定宽，高按比例
  - \=h:指定高，宽按比例
  - \=c:指定高宽裁减（不变形）
  - m:水印
  - 水印：1为右下角，2为左下角，3为左上角，4为右上角，5为居中
  - m=0 不加水印

- 2. 示例

  - <http://www.yqsite.com/cn/images/@cms_d641f054-36d8-4f55-8813-be55aaf0c253.jpg?w=300&h=200&t=c&m=1>
  - 服务器对应保存文件名：d641f054-36d8-4f55-8813-be55aaf0c253.300.200c1.jpg

# 三、模板文件程序类型

  - 文件类型：html
  - 外部请求：html（请求html时先检查模板文件是否存在）

# 四、api接口程序类型

- 1. 文件类型：html
  - 外部请求：json（请求json时先检查是否有同名的html文件，如没有抛出异常）
- 2. api目录，文件类型json，其他文件类型不可使用，程序文件在“api”目录下，文件类型：html。

# 五、程序路由

- 1. 系统handler：对应文件类型前缀“_”，文件类型html。系统handler未定义，对应handler目录下的脚本文件进行处理，文件名去除前缀“_”。
- 2. 非网站目录：scripts、yqwin、adp、login、jsvm。
- 3. url不允许使用目录：svrfunc、handler 

# 六、服务端路由规则

## 6.1 系统服务

- 1. 执行handler，文件前缀 “-” && 文件扩展名“html”。
- 2. 数据库文件，文件前缀“!”。
- 3. 存储文件，文件前缀“^”或“@”。
- 4. js、css程序，文件前缀“\`”
- 5. api程序，目录“api” && 文件扩展名“json”。
- 6. 模板脚本文件，文件扩展名“html”。
- 7. 静态文件。

## 6.2 网站服务

- 1. 执行handler，文件前缀 “-” && 文件扩展名“html”。
- 2. 数据库文件，文件前缀“!”。
- 3. 存储文件，文件前缀“^”或“@”。
- 4. js、css程序，文件前缀“\`”
- 5. api程序，目录“api” && 文件扩展名“json”。
- 6. 非网站目录：scripts、yqwin、yqvue、adp、login、account、jsvm。
  - scripts：js、css文件
  - yqwin：uieip客户端框架js、css
  - adp：后台管理程序文件目录
  - login：登录文件程序目录
  - account：会员管理程序目录
  - jsvm：服务端脚本文件测试目录

- 7. 网站模板文件映射，文件扩展名“html”。
  - 模板文件不存在，执行404
  - 网站index目录中
  - pc：404.html
  - moble：404\_1.html
- 8. 静态文件。
  - config config.json配置 websvr/debug 为 false 时，网站进行缓存，缓存时间为 websvr/cachetime ，单位为：分钟。

## 6.3 单点登录服务

- 1. SSO认证相关路由
- 2. +网站服务
