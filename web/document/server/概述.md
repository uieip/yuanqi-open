# 二、Windows主机编译客户端
- go项目在window下编译简易打包
```shell
go build main.go
go build -o gotest.exe main.go
```
- 项目在window下打包成其他系统可运行的文件
- 1) 在window下打包成linux
在项目main.go同级目录下，逐条执行以下命令
```shell
set CGO_ENABLED=0
set GOOS=linux
set GOARCH=amd64
go build -o uieip-linux main.go
```
- 2) 在window下打包成window下可执行文件
```shell
set CGO_ENABLED=0
set GOOS=windows
set GOARCH=amd64
go build -o uieip-windows.exe svr/main.go
```
- 3) 在window下打包成mac系统可执行文件
```shell
set CGO_ENABLED=0
set GOOS=darwin
set GOARCH=amd64
go build -o uieip-mac svr/main.go
```
**windows 使用“nssm”工具进行服务部署**
a) 工具下载地址:http://nssm.cc/download
b) 解压压缩包，根据系统位数选择64或32位程序
c) 打开命令行，运行nssm程序
管理员权限打开命令行工具，切换到nssm.exe所在路径，运行 nssm install，打开程序配置界面，配置项说明：
Path：运行应用程序的程序
Startup directory：应用程序所在的目录
Arguments：应用运行的参数
Service name：生成服务的名称
最后点击install service 完成windows服务安装，在windows服务列表就能看到创建的服务了。
d）常用命令
nssm install servername //创建servername服务，弹出配置界面
nssm start servername //启动服务
nssm stop servername //暂停服务
nssm restart servername //重新启动服务
nssm remove servername //删除创建的servername服务
nssm edit servername//更改servername服务，弹出修改界面
nssm set servername 参数名 参数值 //设置服务参数值
sc delete servername//windows删除服务命令
直接使用windows的服务管理也可以实现服务的操作，服务右键属性 - 恢复即可设置服务挂掉重启等内容。

**linux 服务部署**
使用systemd创建服务
将程序放到合适位置（例如/etc/uieip）
```
sudo cp uieip-linux /etc/uieip/
sudo chmod +x /etc/uieip/uieip-linux
```
创建服务配置文件 /etc/systemd/system/uieip.service：
```
[Unit]
Description=UIEIP Service
After=network.target

[Service]
Type=simple
ExecStart=/etc/uieip/uieip-linux
WorkingDirectory=/etc/uieip
User=root
Group=root
Restart=always
RestartSec=5
# 如果程序需要特定环境变量
# Environment="KEY=value"

[Install]
WantedBy=multi-user.target
```
重新加载systemd并启用服务：
```
sudo systemctl daemon-reload
sudo systemctl enable uieip
sudo systemctl start uieip
```
检查服务状态：
```
sudo systemctl status uieip
```

停止 SSH 服务
```
sudo systemctl stop uieip
```
启动服务
```
sudo systemctl start uieip
```

# 五、git常用命令
基础提交流程

| 命令 | 作用 |
| ---- | ---- |
| git add <file> | 将工作区文件添加到暂存区 |
| git add . | 添加所有修改的文件 |
| git add -p | 交互式选择部分修改内容 |
| git commit -m | "提交信息"	提交暂存区内容到本地仓库 |
| git commit -am | "提交信息"	自动 add 已跟踪文件并提交（不包含新文件） |
| git pull | 提交到git |
| git push | 下载最终版本数据 |

1. 提交示例
```
git add .
git commit -m "upp"
git push
```
3. 拉取示例
```
git pull
```
