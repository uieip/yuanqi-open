# 一、 概述

## 1.1 目标

构建安全、可靠、易用的企业单点登录系统（SSO），实现用户一次登录即可访问所有授权应用系统，提升用户体验，简化系统管理。

## 1.2 范围

- SSO认证中心，提供统一的用户认证和授权服务。
- 集成现有企业应用系统，实现单点登录功能。
- 提供完善的用户管理、权限管理、日志审计等功能。
- 完善的API接口文档，方便第三方系统集成。

# 二、 功能需求

## 2.1 核心功能

- **用户认证:** 支持用户名密码、短信/邮件验证码、图形验证码及微信第三方登录等认证方式；动态令牌、生物识别等 MFA 能力尚未实现（规划中）。
- **单点登录:** 用户登录一次即可访问所有授权应用系统，无需重复登录。
- **单点登出:** 用户登出当前登录的系统。
- **权限管理:** 基于应用系统的权限控制，控制用户访问权限。

## 2.2 辅助功能

- **用户管理:** 用户注册、信息修改、密码重置等功能。
- **应用管理:** 应用系统注册、授权、注销等功能。
- **日志审计:** 记录用户登录、退出等操作日志，方便审计追踪。
- **安全防护:** 防止暴力破解、SQL 注入、XSS 攻击等安全威胁。

***

# 三、 功能规划

## 1. 用户身份认证

- **统一认证**：提供统一的登录入口，支持多种认证方式（如用户名密码、短信验证码）。
- **认证状态管理**：管理用户的登录状态，支持单点登录（SSO）和单点登出（SLO）。
- **多因素认证（MFA）**：尚未实现（规划中），当前仅支持单一密码/验证码因子的登录校验。

***

## 2. 用户基础信息管理

- **用户信息同步**：以本系统 hr_user/hr_login/hr_org 为唯一用户源，内置 LDAP 服务对外提供账号 Bind/Search；与外部 AD/HR 目录的自动同步尚未实现（规划中）。
- **用户属性管理**：存储和管理用户的基础属性（如用户名、邮箱、部门等），供业务系统使用。
- **用户组管理**：支持用户分组管理，便于业务系统基于用户组进行权限分配。

***

## 3. 单点登出（SLO）

- **登出回调**：提供登出回调接口，业务系统可以实现登出逻辑。

***

## 4. 审计与日志

- **登录日志**：记录用户的登录时间、IP 地址、登录方式等信息。
- **异常日志**：记录认证失败的尝试等异常情况。

***

## 5. 安全与合规

- **权限最小化**：确保 SSO 系统只提供登录许可校验，不涉及业务系统的具体操作权限。
- **数据加密**：对认证令牌和传输的数据进行加密，确保安全性。
- **合规性检查**：确保系统符合相关的安全标准和法规。

***

## 6. 集成与扩展

- **业务系统集成**：提供标准的 API 和协议支持，方便业务系统集成 SSO 功能。

***

## 7. 自助服务

- **用户信息查询**：用户可以通过 SSO 系统查询自己的基础信息。
- **权限申请**：用户可以通过 SSO 系统申请访问某个业务系统，触发审批流程。

***

# 四、总结

在这种目标下，SSO 系统的权限管理功能主要集中在**用户认证**、**基础权限信息的传递**和**令牌管理**上。具体的操作权限由各自的业务系统负责，SSO 系统通过标准化协议（OAuth2）将用户的角色、权限范围等信息传递给业务系统，业务系统再根据这些信息进行本地权限验证和控制。这种设计实现了认证与授权的分离，既保证了系统的安全性，又提高了灵活性和可扩展性。

- 产品核心能力

核心价值在于提供一套集中式的账号、权限、认证和审计工具，解决企业内部身份数据孤岛的问题。它的主要能力体现在以下几个方面：

| 能力模块    | 具体功能与特点                                                  |
| ------- | -------------------------------------------------------- |
| 统一身份源集成 |  内置 LDAP 服务（svradmin/ldap，Bind/Search），基于 hr_user/hr_org 对外提供账号认证与组织查询；支持微信第三方账号绑定。钉钉、企业微信、飞书、AD 等外部目录的自动同步与全生命周期管理尚未实现（规划中）。 |
| 丰富认证协议  |  支持 **SAML2、OAuth2、OIDC、CAS 2.0** 等主流标准协议，并提供 **LDAP**（Bind/Search）与 **远齐SSO** 兼容协议，能广泛对接各类应用。 |
| 多种认证方式  |  除用户名密码、短信/邮件验证码、图形验证码外，还支持微信（公众号内授权 / 开放平台扫码）第三方绑定登录；QQ 等其他社交登录及多因素认证（MFA）尚未实现（规划中）。 |
| 安全与审计   |  具备防暴力破解、会话管理、密码策略等安全能力，并提供详尽的行为审计日志，便于追溯和合规。            |
