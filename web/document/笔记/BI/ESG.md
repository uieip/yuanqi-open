# ESG是什么
ESG 即环境（Environmental）、社会（Social）和治理（Governance）单词首字母的缩写。从环境、社会和公司治理三个维度评估企业经营的可持续性与对社会价值观念的影响。
![](/document/笔记/bi/esg-1.jpg)
ESG理念自2007年被首次提出后，在这十几年间不断扩充其内涵与涵盖范围。在此发展过程中，众多国际机构与评级企业从多角度出发推动ESG行业前进，ESG地位在逐日攀升。且ESG影响力已辐射至投资领域，成为投资策略中举足轻重的内容。
# ESG起源
![](/document/笔记/bi/esg-2.jpg)
1. ESG理念最初是从18世纪早期的伦理投资开始的，尽管当时并无ESG这个概念，但是其理念已经初具ESG雏形。当时的卫理公会号召其信徒不要让他们的企业伤害他们的邻居。它不允许自己的信徒经营一些化工、制革类企业，因为这样的企业可能会给周围环境和社区带来污染。
2. 到20世纪中期，开始进入早期社会责任投资阶段。曾经有这样一张照片，是在越战期间，一个被凝固汽油弹攻击的小姑娘，赤身裸体地在道路上哭喊着奔跑。该照片后来获得了普利策新闻奖，照片公布之后，引发了美国民众对于军火企业的反对浪潮。凝固汽油弹是由陶氏化学公司制造的，该企业当时在美国受到了民众的强烈抵制。此事件的发酵在一定程度上推动了后续ESG理念形成。
3. ESG被正式确立或者说提出通常都认为在1972年。1972年，在斯德哥尔摩举行了联合国人类环境会议，会议为环境保护共同方案的出台铺平了道路，并由此促进了1997年《京都议定书》和2016年《巴黎协定》等一系列与环境保护相关倡议的出台。
4. 1987年，挪威女首相布伦特兰代表联合国出版了《我们共同的未来》，成为ESG发展的另一个重要里程碑。报告重点关注了多边主义和各国在实现可持续发展方面的相互依存关系。
5. 从1992年始，联合国开始举办环境与发展会议，率先提出《21世纪议程》，倡导在促进发展的同时注重环境的保护成为世界范围内注重经济可持续发展的开端。
6. 2006年，联合国在纽交所发布了责任投资原则，从国际社会层面进一步整合社会责任投资的相关问题。截至2018年8月，来自60多个国家的2,000多家投资机构签署了这一文件，这些机构目前管理着约80万亿美元的基金。
7. ESG概念的正式提出是在2007年，由高盛首次提出，旨在将环境、社会以及公司治理的因素纳入投资决策中，关注企业在上述三个维度的表现，降低投资中的非财务风险。

ESG发展至今内容不断扩充，对于ESG的要求，欧盟、美国、新加坡、日本及中国都有自身的理论体系，核心内容大致相同但具体实施要求仍有差异。深圳千合将结合三大国际组织的指引(ISO26000、SASB、GRI可持续发展)、ESG评级公司关于ESG评级的披露信息，为大家整合如下较为完整的ESG内容。
# ESG评价体系
与传统财务指标不同，ESG指标能够更有效地衡量企业的可持续发展能力和道德影响，帮助投资者更好地预判公司未来的财务情况以及绩效。
具体来说，环境主要包含气候变化、可持续性等议题；社会主要包含多样性、人权等议题；而治理则主要包含管理架构、薪酬等议题。
![](/document/笔记/bi/esg-3.jpg)
ESG评价体系又称ESG评级（ESG Ratings），是由商业和非营利组织创建的，以评估企业的承诺、业绩、商业模式和结构如何与可持续发展目标相一致。它们首先被投资公司用来筛选或评估其各种基金和投资组合中的公司。求职者、客户和其他人在评估商业关系时也可以使用这些评级，而被评级的公司本身也可以更好地了解他们的优势、劣势、风险和机会。
ESG理念分为环境、社会和公司治理三个维度：
1. 环境（Environment）：环境因素关注企业对自然环境的影响，包括碳排放、气候变化脆弱性、生物多样性、废弃物管理、清洁技术机遇、能源使用/消费、产品碳足迹、水资源、有害排放、可再生能源机遇等；
2. 社会（Social）：社会因素关注企业对员工、供应链、社区、客户等利益相关方的影响，包括职工健康与安全、人力资本发展、人权政策、化学物质安全性、劳工管理、供应链劳工标准、隐私与数据安全、产品安全与质量、社区关系、争议采购、沟通渠道等；
3. 治理（Governance）：治理因素关注企业的决策、管理结构、透明度和问责制度等方面，包括董事会结构（独立性及多样性）、高管薪酬、商业道德、税务透明度、反贪污、反不公平竞争、企业风险管理等。
对于企业或机构组织来说，ESG的内容并不是在其业务范围外新增的内容，而是基于业务本身，从实际出发，在业务发展与改进的方向中融入ESG理念，进行企业的可持续发展转型。

当然，在这其中也存在很多实际问题，比如说像是化石能源转变为清洁能源的使用，对于企业成本的增加、企业设备的更新都会提出要求，对企业运营来说是严峻的挑战。除企业本身的因素外，客观条件的限制也是ESG发展的阻力之一，比如对于温室气体排放的管理方面，涉及到范围三的排放，包含产品原材料运输及产品售出后使用过程中的排放，但这一部分需要众多供应链企业的配合，目前暂未有完善的供应链碳排放数据管理系统，供应链上下游企业对于这部分数据的核查与记录能力较薄弱，这也是当下ESG发展正在全力解决的问题。
# ESG表现与ESG投资
通过前面两部分的介绍，我们大致了解何为ESG以及ESG的内涵，那么来到实际应用阶段，ESG理念的应用在实际中如何发挥作用。
之前我们常说，评判一个企业是否值得投资，要从财务基本面情况来分析，比如盈利状况、偿债能力、现金流等，而ESG概念出现以后，越来越多的投资机构推出ESG投资，一家值得投资的公司不仅要会赚钱，更要有可持续的社会责任感，也就是更多将投资关注点偏移至ESG表现上。企业的ESG表现当下以ESG评级或评分形式来体现，投资者也多以此作为判断依据。
与ESG披露要求相似的是，ESG评级/评分标准也暂未形成统一的要求，市场上的ESG评级机构呈现百花齐放的态势。常用的ESG评级包括摩根士丹利资本国际公司 (MSCI)、标普道琼斯、晨星（Sustainalytics）、路孚特（REFINITIV）、富时罗素（FTSE）、社会价值投资联盟（CASVI）、商道融绿、万得 (WIND)等。
除了这些直接的评级可以证明企业的ESG表现优越性以外，仍有许多支持ESG理念的国际组织，对于ESG其中某一些议题进行更加深入地分析，满足其要求的组织与企业才可加入该组织或响应其号召，以彰显ESG优越性。比如科学碳目标倡议（SBTi）、联合国责任投资原则组织（UN PRI）、联合国全球契约（UNGC）、气候变化机构投资者组织（IIGCC）等。
金融机构、私募股权公司和个人投资者现在更加关注 ESG，并越来越多地寻求可持续投资。这导致了区分 ESG 合规和不合规选项的新方法开发。通过许多策略对可持续投资进行了定义：
1. 负面筛选——排除被认为不可持续的资产或公司，例如烟草公司或武器制造商；
2. 正面筛选——选择具备ESG 积极成果的公司；
3. ESG整合——将ESG因素纳入投资流程；
4. 影响力投资——一项雄心勃勃的战略，投资者只投资于 ESG 影响力可以精确量化的公司；
5. 主题投资——选择考虑ESG相关主题的公司；
6. 基于规范的筛选——识别遵守联合国、国际劳工组织、经济合作与发展组织等国际规范的公司。

# ESG评价体系工作流程
ESG评级的工作流程主要由三部分组成：
1. 一是数据采集和信息归纳
2. 二是指标设置、评分评级和形成评级结果
3. 三是将评级结果指数化，从而形成服务投资的产品
