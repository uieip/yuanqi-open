# ESG
ESG披露是指企业在其商业活动中积极考虑环境（Environment）、社会（Social）和治理（Governance）等ESG因素，并将这些信息公开向投资者、消费者和其他利益相关者披露的过程。
ESG因素包括企业在其经营活动中对环境、社会和治理等方面的影响。环境因素包括企业是否遵守环保法规、是否采用可再生能源、是否减少废水和废气等。社会因素包括企业是否尊重劳工权益、是否尊重人权、是否对社区做出贡献等。治理因素包括企业的经营与管理是否规范、是否遵守监管法规等。
通过将ESG信息公开披露，投资者等利益相关者能够更好地了解企业的可持续发展战略、管理方式以及其对社会、环境的影响等信息。同时，ESG披露也可以帮助企业提高透明度和可持续性，吸引更多的投资和消费，并促进企业和整个社会的可持续发展。因此，ESG披露也被认为是企业社会责任的一个重要方面。
