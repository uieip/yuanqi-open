文件为一种特殊的字段类型，分为表内文件及表外文件。
# 一、表内文件
文件存储在表内。

- sys_files 表内文件

| No. | 字段名 | 标题 | 字段类型 | 备注 |
| -- | --- | --- | --- | --- |
| 1 | sid | sid | varchar |  |
| 2 | type | 文件类型 | varchar |  |
| 3 | size | 大小 | int4 |  |
| 4 | name | 文件名称 | varchar |  |
| 5 | finger | 文件指纹 | varchar |  |
| 6 | data | 文件数据 | bytea |  |
| 7 | c\_userid | c\_userid | varchar |  |
| 8 | c\_username | c\_username | varchar |  |
| 9 | createtime | createtime | timestamp |  |
| 10 | linknum | 关联数量 | int4 | - |

- sys_files_rel 表内文件关联

| No. | 字段名 | 标题 | 字段类型 | 备注 |
| -- | --- | --- | --- | --- |
| 1 | sid | sid | varchar |  |
| 2 | file\_id | 表内文件sid | varchar |  |
| 3 | tb\_name | 文件名 | varchar |  |
| 4 | tb\_id | 文件sid | varchar |  |
| 5 | tb\_field | 字段sid | varchar |  |
| 6 | c\_userid | c\_userid | varchar |  |
| 7 | c\_username | c\_username | varchar |  |
| 8 | createtime | createtime | timestamp | - |

# 二、表外文件

| -- | --- | --- | --- | --- |

| 5 | finger | 文件指纹 | varchar |  |
| 6 | path | 文件位置 | varchar |  |
| 7 | c\_userid | c\_userid | varchar |  |
| 8 | c\_username | c\_username | varchar |  |
| 9 | createtime | createtime | timestamp |  |
| 10 | linknum | 关联数量 | int4 | - |
