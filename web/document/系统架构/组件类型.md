# 一、简介

单一组件（文本框textbox、是否、下拉框、....）
符合组件（属性attr、表table、树tree），由单一、符合组件叠加而成

- UI展现形式
  属性（attr）、form表单
  表格（table）、下拉表格选择
  树形（tree）、下拉树形选择
- 数据记录格式
  attr（单）、table（多）、tree（多）
- 数据格式描述分为单数据、多数据，单数据为{},多数据为\[]
  attr：{}
  table：\[{},…]
  tree：\[{,subs:\[{},…]},…]
- *is_func*
	- 是否为函数组件，true、false
	- true：组件值为函数，需要在运行时调用
	- false：组件值为普通文本，直接展示
	- func：组件值为函数，需要在运行时调用
	- 示例函数：

```javascript
{
    name: "comment",
	ui_type: 0,
	ui_title: "评论",
	ui_width: 100,
	is_func: true,
	func: t(row,value) {
		return "re:" + value;
	},
}
```
