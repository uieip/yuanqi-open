# 一、中国股票市场的交易规则
以上海证券交易所和深圳证券交易所为主。
## 1.1 交易时间
- 开盘集合竞价：9:15-9:25（其中9:15-9:20可挂单/撤单，9:20-9:25仅可挂单不可撤单）。
- 连续竞价（早盘）：9:30-11:30。
- 午间休市：11:30-13:00。
- 连续竞价（午盘）：13:00-14:57。
- 收盘集合竞价：14:57-15:00（仅接受挂单，不可撤单）。
- 科创板/创业板盘后固定价格交易：15:05-15:30（按当日收盘价成交）。

| 时段 | 可否挂单 | 可否撤单 |
| ---- | ---- | ---- |
| 开盘集合竞价（9:20-9:25） | ✅ 可以 | ❌ 不可 |
| 连续竞价（9:30-11:30、13:00-14:57） | ✅ 可以 | ✅ 可以 |
| 收盘集合竞价（14:57-15:00） | ✅ 可以 | ❌ 不可 |
| 临时停牌期间 | ❌ 不可 | ❌ 不可 |

## 1.2 涨跌幅限制
- 主板股票：新股首日最高涨幅44%，之后每日涨跌幅10%（ST股为5%）。
- 科创板（688开头）、创业板（300开头）：新股前5个交易日无涨跌幅限制，之后每日涨跌幅20%。
- 北交所（8开头）：新股首日无涨跌幅限制，之后每日涨跌幅30%。

## 1.3 T+1交易制度
当日买入的股票需第二个交易日（T+1）才能卖出，但资金当日卖出后可继续买入股票。

## 1.4 下单类型
- 限价委托：指定价格买卖，未成交前可撤单。
- 市价委托（部分市场适用）：按实时最优价格成交（如五档即时成交剩余撤销）。
- 集合竞价订单：仅在开盘/收盘集合竞价阶段参与撮合。

## 1.5 回测规则
- 回测（Backtesting）指用历史数据模拟交易策略的效果，非交易所规则，但需注意：
- 需考虑历史数据的完整性（如除权除息调整）。
- 实际交易中需考虑滑点、手续费等成本。

## 1.6 结算规则
- 资金结算：T日卖出股票的资金T+0可用（可买股票），T+1可取（转出银行）。
- 股票交割：T日买入的股票T+1日到账，卖出后T+1日资金正式清算。

## 1.7 其他规则
- 最小交易单位：1手=100股（科创板/北交所可单股买卖）。
- 手续费：包括佣金（券商收取，通常≤0.03%）、印花税（卖出时0.05%）、过户费（0.001%）。
- 大宗交易：单笔交易数量或金额达到门槛（如30万股或200万元）可通过大宗交易通道完成。

## 1.8 注意事项
- 新股上市首日可能临时停牌（如涨幅超10%停牌30分钟）。
- 风险警示股票（ST/*ST）有特殊交易限制（如涨跌幅5%）。

# 二、交易系统
## 2.1 核心逻辑
**让利润奔跑，但锁定部分盈利。**
- **跟随趋势：**
均线天然反映趋势方向（向上或向下）。只要价格保持在关键均线（如10日、20日、60日均线）上方，默认趋势仍在延续，此时持仓可捕捉更多利润。
- **动态防守：**
当盈利达到一定程度后，将止损位（止盈位）从初始固定点位上移至当前均线附近。这样既能保护部分盈利，又避免过早离场。
- **截断亏损，让利润奔跑：**
若价格回调跌破均线，视为趋势可能反转信号，自动触发止盈，锁定大部分盈利。


## 炒股实操五条要点
- 1、选股思路：优选价值洼地，回避高位热门标的
   -规避经过短线爆炒、股价脱离自身基本面的题材妖股；优先挑选行业发展景气平稳、股价历经长期回调、估值处在历史低位的个股。
   -做好持仓分散配置：单个账户固定持仓 3～5 只股票，不把全部资金重仓单一标的，以此防范个股突发黑天鹅带来的暴雷风险。
   -选股立足企业基本面，重点关注上市公司主营业务盈利水平，摒弃各类短期炒作题材、不实内幕传言以及网红荐股信息。
- 2、买卖准则：下跌分批低吸，上涨分批止盈
   -下跌行情中：个股回调至自身预设安全价位时分层加仓，杜绝一次性满仓操作；若持仓深度被套，不慌乱盲目割肉，依托低位加仓摊薄持仓成本。
   -上涨行情中：股价触及预先设定的盈利目标后，分阶段卖出获利筹码，摒弃贪婪死拿导致收益回撤坐过山车；股价涨幅超出预期时循序渐进减仓落袋，不主观臆想股价持续无限上涨。
- 3、仓位管理：合理管控仓位，从源头控制亏损（核心要点）
   -大盘处于低位、市场整体情绪恐慌时，仓位可提升至 6～7 成；大盘位于高位、市场全民炒股氛围浓厚时，仓位收缩至 1～3 成，市场行情极端火热则直接空仓观望。
   -严守资金底线，禁止借贷炒股、融资加杠杆，仅使用个人闲置自有资金参与投资，从根本上规避巨额亏损隐患。
- 4、心态管理：秉持长线耐心，摒弃频繁交易
   -频繁换股、短线反复进出是散户亏损的首要原因，交易手续费叠加高位追买带来的亏损，会大幅蚕食投资收益。
   -个股建仓完成后减少盘中盯盘频率，看淡单日股价涨跌波动，以季度、半年度的中长期视角持有筹码，依靠时间消化盘面短期震荡。
克服投资人性弱点：行情大跌时恐慌割肉、行情大涨时盲目追涨，是多数投资者亏损的关键诱因。
- 5、规避散户三大典型投资误区
   - 误区 1：盲目跟风内幕消息、直播间荐股，此类个股大多为主力借机出货、诱导散户接盘的陷阱；
   - 误区 2：缺少固定交易纪律，要么出现亏损后一味死扛不愿止损，要么小幅亏损就仓促割肉离场；
   - 误区 3：妄图抓住每一轮短线牛股行情，频繁更换投资赛道，最终容易两头踏空、一无所获。
