# **一、波浪理论**
## 1.1 波浪理论概述
艾略特波浪理论是股票技术分析的一种理论，由5个主波和3个修正波构成，具体可以参考下图。
**1、**

上升趋势中1到5波和ABC修正波
![](/document/股票/趋势分析/波浪理论-2.jpg)
下降趋势中1到5波和ABC修正波

**2、**
艾略特波浪理论的4大定律
- 1）二浪回撤不能大于一浪的100%
- 2）三浪不能最短
- 3）四浪回撤不能和一浪重叠
- 4）二浪和四浪交替原则
![](/document/股票/趋势分析/波浪理论-3.jpg)

   行情中，股价的波动总是延续着上涨-修正-上涨-修正-上涨-转折；
   行情中，股价的波动总是延续着下跌-修正-下跌-修正-下跌-转折。
![](/document/股票/趋势分析/波浪理论-4.jpg)
MACD中0轴是多空分界线，是趋势的停顿与转折，一般也是大行情的爆发点。艾略特波浪理论中，修正波的目的就是把MACD拉回0轴，使价格达到多空平衡，然后多空双方再进行一次较量，所以0轴是修正波结束的位置。0轴上方是多头市场，MACD指标线回0时就是买点。0轴下方是空头市场，MACD指标线回0时就是卖点。

**3、**
**MACD定浪法则**
1、一浪上0轴，也就是股价从高位跌破60线以后的最低点是一浪的起始点，上穿60线之后的第一高点是一浪的终点；
2、二浪不能低于一浪的起点，可以破60线也可以不破；
3、三浪最大峰值，也就是三浪macd的指标线峰值最大；
4、四浪低点不能破一浪的顶；
5、五浪和三浪的macd形成顶背离。
![](/document/股票/趋势分析/波浪理论-5.jpg)

**4、**
1、一堆红柱是一个上升浪，一堆绿柱是一个下跌浪；
2、两个上升浪之间必须有绿柱隔开，两个下跌浪之间必须由红柱隔开。
![](/document/股票/趋势分析/波浪理论-6.jpg)

**5、**
MACD回0轴方式
1、MACD被动回0轴。一般MACD回0轴时，股价是横盘整理，等60线跟上来，MACD缓慢的向下靠近0轴。
![](/document/股票/趋势分析/波浪理论-7.jpg)
运用：当MACD回0轴，股价在横盘的时候，我们就要想到是被动回0方式。当MACD绿柱缩小，红柱出现并不断放大，0轴上指标线金叉并突破横盘平台时，可以买进或突破后回踩再起然后买进。
![](/document/股票/趋势分析/波浪理论-8.jpg)
2、MACD主动回0轴。MACD回0轴时，股价主动向60线跌。
![](/document/股票/趋势分析/波浪理论-9.jpg)
运用：如图，股价回靠到60线处得到支撑，MACD绿柱缩短，红柱出现并不断放大，回0轴金叉时买进。
![](/document/股票/趋势分析/波浪理论-10.jpg)
3、ABC回0轴。股价回靠60线时，中途会有一次反弹，形成ABC走势。股价反弹时，MACD回0轴时也金叉，股价再回落时再次死叉。
![](/document/股票/趋势分析/波浪理论-11.jpg)
运用：途中A点时可以买进，不过注意反弹到0.5到0.618时候的回撤先及时止盈离场，等C点时可以再买进。
![](/document/股票/趋势分析/波浪理论-12.jpg)

## 1.2 波浪理论的缺陷
波浪理论没有统一的绝对的标准，只有一个大致的数浪规则。会出现两个问题，要么在同一段行情的不同时间里，数出不一样的波浪来；要么是在同一段行情里，不同的人数出不同的波浪来。
数波浪的主观性太强，一千个人可能就会数出一千种浪来，这就是波浪理论的缺陷：没有明确标准，千人千浪。
## 1.3 两种量化数浪的方法
实战中，我们可以在k线上加入一些指标，来帮助我们把数浪的标准明确化，这样不同的人看不同的行情，都可以找到标准一致的波浪，避免交易中出错。

**方法1：ZigZag数浪**
ZigZag指标是软件上自动生成的，可以自动识别行情的高低点。实战中，我们可以用这个指标自动选取的高低点，作为波浪的启动点和结束点进行数浪。
这样操作后，就不需要人为的判断，指标自动识别后，我们就可以进行数浪，这样每次数浪的标准就会保持一致性，非常有实战意义。
大家看下方的示意图：
![](/document/股票/趋势分析/波浪理论-量化-1.jpg)
在图表上加载ZigZag指标之后，就可以自动识别行情的高低点。指标连接的高低点，就可以自动读取为1个浪，图中蓝色向上的箭头是驱动浪，红色回调的箭头是整理浪，非常清晰明了。

**方法2：布林数浪**
图表上加入布林带之后， k线会沿着布林带的上轨和下轨运行。读取k线从布林下轨到上轨，或者布林上轨到下轨的走势为一个波浪。
大家看示意图：
![](/document/股票/趋势分析/波浪理论-量化-2.jpg)
图中是用布林数浪的示意图。k线的低点从布林带下轨启动，作为一浪的启动点，测试到上轨的高点之后，确认为驱动浪。
k线的高点从布林的上轨启动测试到布林带下轨，确定为调整浪。图中蓝色的箭头为驱动浪，红色的箭头为向下的调整浪。

## 1.4 两种波浪的实战方法
**方法1：ZigZag指标数浪交易。**
根据波浪理论，完整的波浪趋势会走3个驱动浪和2个调整浪，当第1个驱动浪走势确立之后，等待整理浪回调，回调结束，ZigZag指标形成折点之后进场。
进场之后，行情突破第1个驱动浪的高点，走出3浪之后，再次形成4浪的回调。4浪回调结束，ZigZag指标再次形成折点后，加仓进场。
行情突破4浪的高点，形成5浪，5浪冲高后，行情有走反向ABC的可能，此时平仓。
大家看示意图：
![](/document/股票/趋势分析/波浪理论-量化-3.jpg)
图中左侧是一波多头波浪的走势。
第1浪确定之后，行情展开回调，ZigZag指标形成折点，此时结合k线形态进场做多。
行情启动破高走出3浪之后，展开回调，形成整理浪。整理结束，ZigZag指标再次形成折点后，结合k线形态加仓做多。行情再次启动破高，走出延展浪，冲高后，行情有走反向ABC的可能，此时平仓。
图中右侧是一波空头波浪的走势。
第1浪确定之后，行情展开调整，ZigZag指标形成折点，此时结合k线形态进场做空。
行情启动破低走出3浪之后，再次形成整理浪，调整结束，ZigZag指标再次形成折点，结合k线形态加仓做空，行情再次启动破低。
由于3浪走了一个非常明显的延展浪，5浪走大空间的概率并不高，5浪形成之后平仓。

**方法2：布林数浪交易**
用布林数浪交易的方法，和ZigZag指标交易的逻辑是一样的，也是根据3个驱动浪+2个调整浪的波浪理论进行交易。在2浪调整结束的位置进场，在4浪的调整结束的位置加仓，五浪形成之后平仓。
大家看示意图：
![](/document/股票/趋势分析/波浪理论-量化-4.jpg)
图中左侧是一波下跌的波浪走势。2浪回调的位置开仓，4浪回调的位置加仓，5浪形成之后平仓出局。
图中右侧是一波上涨的波浪走势。在2浪回调的位置开仓，3浪形成了延展浪，4浪经过短暂的回调加仓，行情破高走出5浪之后，平仓出局。
## 1.5 交易方法的注意事项
第一：建议采用金字塔加仓的方法交易，加仓的仓位要比开仓的仓位小一些，这样更容易执行。
第二：这属于一种趋势性的交易策略，交易的成功率不会特别高，实战之前一定要先做复盘，确保自己的能接受度。
第三：可以用在15分钟，1小时，4小时的周期进行交易。再小的周期，交易频率过高，稳定性会比较差，更大的周期，持仓的时间太长，太考验耐心，都不利于执行。
波浪理论本质上就是道氏理论的变形，道氏理论中的趋势就是以波浪的形式推进的。行情有波峰波谷，也就是波浪理论中的驱动浪和调整浪。
波浪理论在道氏理论的基础上，做了更细致的结构划分，因此还是非常有实战意义的。
