# 1. 加载程序文件
- base：基础程序加载（不进行任何操作）
```html
<uieip type="page" value="base"></uieip>
```
- login：登录判断，如果登录继续执行，未登录调转到登录页面
```html
<uieip type="page" value="login" debug="true" timeout="5000"></uieip>
```

1. debug:开启debug
   当debug配置不存在时，取config配置debug。当debug为false时，页面内js程序执行压缩处理。
2. timeout:执行过期时间
   当timeout配置不存在时，取config配置timeout。
3. ~~checkcross：校验跨域~~（已废弃）
   跨域校验已统一由服务端中间件（websvr/appauth 中间件）强制执行，脚本无法通过该参数绕过。
4. method：post、get 校验
   当method为post，只允许POST请求，当method为get，只允许GET请求，其它运行POST、GET（都允许）。
# 2.函数注册引用
```html
<uieip type="reg" value="console,cms"></uieip>
```
request、response 默认会加载，无需引用
## 2.1 request：获取页面参数接口
- 1) dataset：通过id设置tmpl传递的数据
```html
request.dataset("_id","value");
request.dataset("_id2",{"name":value"});
request.dataset("_id3",[{"name":value"}]);
```

- 2) data：通过id获取tmpl传递的数据
```html
var a = request.data(“_id2”);
```
没有值，返回：null

- 3) set：通过id设置tmpl的html数据
```html
var id = "aaa";
var val = "<a>aaaa</a>";
request.set(id,val);
```

- 4) get：通过id获取tmpl的html数据    return string
```html
var id = "aaa";
var i_html = request.get(id);
```

- 5) param：获取url？参数    return string
```html
var a = request.param(“aaa”);
```
没有值，返回：null

- 6) scheme：获取scheme    return string
```html
var a = request.scheme();
```

- 7) host：获取host   return string
```html
var a = request.host();
```

- 8) url：获取url    return string
```html
var a = request.url();
```

- 9) pathval：获取url截取参数（cms）  
   返回值示例 {"path":"news","name":"page1","page":1}
```html
var a = request.pathval();
```

- 10) isPostback：from表单，页面是否为postback状态  
   返回值示例 false 或 true
```html
var a = request.isPostback();
```
- 11) ip：获取客户端ip
   返回值：string类型
```html
var a = request.ip();
```

- 12) formGetValue：from表单，通过name读取表单数据
   返回值：string类型
```html
var a = request.formGetValue("text_name");
```

- 13) formSetValue：from表单，通过name读取表单数据
   返回值：undefined
```html
request.formSetValue("option2", ["option2", "option3"]);
request.formSetValue("txt_input", "开始测试");
```

- 14）cookie_get：获取cookie值
输入参数：
name：名称，string类型
返回值：string
```html
var val = request.cookie_get("name");
```
- 15）cookie_set：设置cookie值
输入参数：
name：名称，string类型
value:值，string类型
expire：过期时间（单位：分钟）
返回值：undefined
```html
request.cookie_set("name","name_123",60 * 24 * 30);
```
- 16）~~isCrossOrigin：检查是否为跨域请求~~（已废弃）
  跨域校验已统一由服务端中间件（websvr/appauth 中间件）强制执行：非白名单跨域请求在中间件即被 433 拒绝，脚本内不再需要也无法查询跨域状态。

- 17） body：获取页面body数据
输入参数：
toString：是否输出string类型，如果为true，则返回string，否则返回byte[]
返回：默认，值为byte[]类型，如果toString==true，值为string类型
```html
var a = request.body();        //a 为byte[]类型
var b = request.body(true);    //b 为string类型
var c = request.body(false);   //c 为byte[]类型
var d = request.body(1);       //d 为string类型
var e = request.body(0);       //e 为byte[]类型
```

## 2.2 response：文档操作接口

- 1) set：通过id向文档流写入数据
```html
var id = "aaaa";
var val = "<p>hello word!</p>";
response.set(id,val);
```
- 2) write：向文档流写入数据
```html
response.write("Hello word.");
```

- 3)  scriptbegin
```html
response.scriptbegin();
```
页面写入
```html
<script>
```

- 4)  scriptend
```html
response.scriptend();
```
页面写入
```html
</script>
```
- 5) redirect：跳转到特定页面
```html
response.redirect(“index.html”);
```

- 6） body：设置页面body数据
输入：值为 string、byte[] 等类型均可
```html
response.body('string');
```

- 7） contentType：设置 contentType
输入：string
```html
response.contentType('text/html');
```
可输入：text/html、application/json 等

## 2.3 http
1) 发送POST请求
```javascript
http.post(url, data, headers)
```
- url: 请求地址
- data: 请求数据，支持string或object
- headers: 可选，请求头，object类型

返回值：{error:0, data:响应数据} 或 {error:非0, info:错误信息}
```javascript
// 发送JSON数据
let res = http.post("http://api.example.com/data", {
    name: "test",
    value: 123
}, {
    "Authorization": "Bearer token123"
});

// 发送普通文本
let res2 = http.post("http://api.example.com/text", "Hello World");

// 检查响应
if (res.error === 0) {
    console.log("成功:", res.data);
} else {
    console.log("失败:", res.info);
}
```
2) 发送GET请求
```javascript
http.get(url, headers)；
```
- url: 请求地址
- headers: 可选，请求头，object类型

返回值：{error:0, data:响应数据} 或 {error:非0, info:错误信息}

```javascript
// 简单GET请求
let res = http.get("http://api.example.com/data");

// 带请求头的GET请求
let res2 = http.get("http://api.example.com/data", {
    "Authorization": "Bearer token123",
    "Accept": "application/json"
});

// 检查响应
if (res.error === 0) {
    console.log("成功:", res.data);
} else {
    console.log("失败:", res.info);
}
```

3) 上传文件
```javascript
http.upload(url, files, data, headers);
```
- url: 上传地址
- files: 文件信息数组 [{name: "字段名", path: "文件路径"}, ...]
- data: 可选，附加参数，object类型
- headers: 可选，请求头，object类型

返回值：{error:0, data:响应数据} 或 {error:非0, info:错误信息}
```javascript
// 单文件上传示例
let res = http.upload("http://api.example.com/upload", [
     {name: "file", path: "./test.jpg"}
   ], {
       userId: "123"
   });

// 多文件上传示例
let res2 = http.upload("http://api.example.com/upload", [
    {name: "file1", path: "./test1.jpg"},
    {name: "file2", path: "./test2.jpg"}
  ], {
     userId: "123",
     type: "image"
  }, {
       "Authorization": "Bearer token123"
   });
```

# 3.文件程序处理
## 3.1 inc：文件
```html
<uieip type="file" value="inc" src="src/include.txt" cache="true" minute="1440"></uieip>
```
- catche:参数可选，如不存在，catche为页面（!debug） 存在时：!debug && catche
- minute：缓存时间，单位分钟，设置时使用minute缓存时间，不设置使用默认缓存时间24小时

## 3.2 exec：脚本程序
```html
<uieip type="file" value="exec" src="/cms/inc/pc_topmenu_exec.html"></uieip>
```
## 3.3 js：js文件
```html
<uieip type="file" value="js" src="/jsvm/js/js.txt" cache="true"></uieip>
```
- catche:参数可选，如不存在，catche为页面（!debug），存在使用catche设置
- cathe=true js压缩，压缩文件为；src+".js"

## 3.4 css：css文件
```html
<uieip type="file" value="css" src="/jsvm/js/css.txt" cache="true"></uieip>
```
- catche:参数可选，如不存在，catche为页面（!debug），存在使用catche设置
- cathe=true css压缩，压缩文件为；src+".css"

## 3.5 jsvm：服务端js脚本文件
```html
<uieip type="file" value="jsvm" src="src/cms.js" cache="true" minute="1440"></uieip>
```
- catche:参数可选，如不存在，catche为页面（!debug） 存在时：!debug && catche
- minute：缓存时间，单位分钟，设置时使用minute缓存时间，不设置使用默认缓存时间24小时
- 服务端执行的函数文件。

## 3.6 code：html代码嵌入
```html
<uieip type="file" value="code" src="/jsvm/inc/title.html" cache="true" minute="1440"></uieip>
```
- catche:参数可选，如不存在，catche为页面（!debug） 存在时：!debug && catche
- minute：缓存时间，单位分钟，设置时使用minute缓存时间，不设置使用默认缓存时间24小时
- 格式化标签"<"、">"，代码外部添加"&lt;pre&gt;代码...&lt;/pre&gt;"。
