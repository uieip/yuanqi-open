# 用户登录
# 一、函数
## 1.1 登录状态
```javascript
var lg_state=login.state();
```
返回:
true：登录
false：未登录
## 1.2 登录用户信息
```javascript
var userinfo=login.userinfo();
```
返回:
undefined：未登录，用户信息不存在
成功返回数据格式：{sid:"11111"."name":"demo",...}
## 1.3 校验登录用户是否存在
```javascript
var res=login.check(user_id);
```
请求参数：
user_id：用户id
返回:{error:0,info:"ok"}
error值
0:登录成功
2:用户不存在
3:用户注销，不能登录
99:登录失败，session错误
## 1.4 登录退出
```javascript
login.logout();
```
无返回值
## 1.5 创建用户
```javascript
var res=login.addUser({name:"demo",user_id:"11111111","isdel":false});
```
返回：{error:0,info:"ok"}

## 1.6 解析id_token信息
```html
var res=login.idTokenConvert(id_token);
```
- 返回res值
错误
```json
{
	"error":99,
	"info":"ok"
}
```
## 1.7 登录用户是否管理员
```html
var res=login.isadmin();
```
- 返回res值
是管理员
```json
{
	"error":0,
	"info":"ok"
}
```
不是管理员
```json
{
	"error":99,
	"info":"XXXXX"
}
```
