# 缓存操作接口（cache）
# 一、函数
##1.1 setValue：写入缓存数据
```javascript
var res=cache.setValue(key,val,seconds);
```
- seconds：缓存过期时间，单位：秒，<=0时，不过期

返回数据（示例）
```json
{
   "error":0,
   "info":"ok"
}
```
##1.2 getValue：获取缓存数据
```javascript
var res=cache.getValue(key,seconds);
```
- seconds：缓存过期时间，单位：秒，<=0时，不过期

返回数据（示例）
```json
{
   "error":0,
   "info":"ok",
   "data":"data1"
}
```

##1.3 delete：删除缓存数据
```javascript
var res=cache.delete(key);
```

返回数据（示例）
```json
{
   "error":0,
   "info":"ok"
}
```

```javascript
var res=cache.setsValue(key,sub_key,val,seconds);
```

##1.5 getsValue：获取缓存数据
```javascript
var res=cache.getsValue(key,sub_key,seconds);
```
- seconds：缓存过期时间，单位：秒，<=0时，不过期

返回数据（示例）
```json

   "error":0,
```

##1.6 deletes：删除缓存数据
