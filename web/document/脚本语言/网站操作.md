# 网站操作接口

# 一、函数 cms

## 1.1 title：标题函数

在服务端脚本中调用，生成 `<title>` 和 `<meta name="keywords">`、`<meta name="description">` 标签，并回写到模板中 `cms.title` 的位置。

```html
var r_title = request.data("cms.nav");
cms.title(r_title.nav.Name, "远齐,科技", "远齐科技（北京）有限公司...");
```
或直接设置：
```html
var title = cms.title("标题", "远齐,科技", "远齐科技（北京）有限公司...");
```

**参数说明：**
| 参数 | 必需 | 说明 |
|------|------|------|
| title | 是 | 页面标题，不能为空字符串 |
| keywords | 否 | 页面关键词，多个用逗号分隔 |
| description | 否 | 页面描述 |

**返回值：** 生成的 HTML 字符串，如 `<title>标题</title>\n\t<meta name="keywords" content="...">\n\t...`

**行为说明：**
- 生成的 HTML 会自动回写到模板中 `Stype==4 && Fun=="cms.title"` 的分片位置
- 如果模板中不存在 `cms.title` 分片，函数会返回错误

# 二、模版程序

## 2.1 cms.nav 导航信息

### 模板声明

```html
<uieip id="nav" type="tmpl" value="cms.nav" js="bootstrap"></uieip>
```

**参数说明：**
| 参数 | 必需 | 说明 |
|------|------|------|
| id | 否 | 模板 ID，用于后续通过 `request.data("id")` 获取数据 |
| value | 是 | 固定为 `"cms.nav"` |
| js | 否 | 服务端渲染函数名，指定后在服务端执行该函数生成导航 HTML |

### a) data 格式

```json
{
    "path": "news",
    "name": "page1",
    "page": 1,
    "site": {
        "Title": "远齐云-数字企业 智慧未来",
        "Keywords": "北京网站建设公司,企业网站",
        "Description": "主营业务：...。",
        "IndexUrl": "cms/Index.tpl",
        "IndexUrl1": ""
    },
    "nav": [{
        "Path": "news",
        "Name": "新闻资讯",
        "...": "..."
    }],
    "navs": [{
        "Path": "infor",
        "Name": "新闻资讯",
        "Describe": "新闻资讯",
        "Icon": "",
        "LinkUrl": "",
        "Blank": false,
        "ListUrl": "cms/list.tpl",
        "ShowUrl": "cms/page.tpl",
        "ListUrl1": "",
        "ShowUrl1": "",
        "Tid": "",
        "PTitle": "",
        "PKeywords": "",
        "PDescribe": "",
        "IsDel": false,
        "Subs": []
    }]
}
```

**data 字段说明：**
| 字段 | 类型 | 说明 |
|------|------|------|
| path | string | 当前路径（如 `"news"`） |
| name | string | 当前文件名（不含 `.html`） |
| page | int | 页码（文件名以 `page` 开头时解析，如 `page2.html` → 2） |
| site | object | 站点信息（Title/Keywords/Description/IndexUrl/IndexUrl1） |
| nav | array | 当前导航路径链（从根到当前页面的导航路径） |
| navs | array | 所有导航项数组 |

**NavItem 字段说明：**
| 字段 | 类型 | 说明 |
|------|------|------|
| Path | string | 导航路径（URL 路径部分） |
| Name | string | 导航名称 |
| Describe | string | 导航描述 |
| Icon | string | 图标 CSS 类名 |
| LinkUrl | string | 外部链接 URL（非空时优先使用） |
| Blank | bool | 是否新窗口打开 |
| ListUrl | string | 列表页模板（PC 端） |
| ShowUrl | string | 详情页模板（PC 端） |
| ListUrl1 | string | 列表页模板（移动端） |
| ShowUrl1 | string | 详情页模板（移动端） |
| Tid | string | 关联内容 ID |
| PTitle | string | 页面 SEO 标题 |
| PKeywords | string | 页面 SEO 关键词 |
| PDescribe | string | 页面 SEO 描述 |
| IsDel | bool | 是否已删除 |
| Subs | array | 子导航数组 |

### b) 数据获取

参数数据获取参数为 `cms.nav`
```javascript
var a = request.data("cms.nav");
```

### c) js 渲染函数（服务端脚本）

当模板声明了 `js="函数名"` 时，服务端执行该函数生成导航 HTML。

**示例：顶部导航菜单（完整版）**

取自 [webvue/cms/inc/pc_topmenu_exec.html](file:///d:/Spring/yuanqi.go-vue/webvue/cms/inc/pc_topmenu_exec.html)：

```html
<uieip id="nav" type="tmpl" value="cms.nav" js="bootstrap"></uieip>
<script runat="server">
    function bootstrap(res) {
        // res 包含：
        //   res.navs  — 所有导航项数组
        //   res.path  — 当前路径
        //   res.site  — 站点信息
        var h = bootstrap_html(res.navs, res.path, true);

        // 登录状态处理
        var user_row = login.userinfo();
        h += '<ul class="nav navbar-nav pull-right">';
        if (user_row === undefined) {
            h += '<li><a href="javascript:void(0)" onclick="userlogin();return false;">登录</a></li>';
        } else {
            h += '<li class="dropdown">';
            h += '  <a href="..." class="dropdown-toggle" data-toggle="dropdown">';
            h += '    <b class="glyphicon glyphicon-user"></b> ' + user_row["name"] + '<b class="caret"></b>';
            h += '  </a>';
            h += '  <ul class="dropdown-menu">';
            h += '    <li><a href="/account/index.html">会员中心</a></li>';
            h += '    <li><a href="javascript:void(0)" onclick="userlogout();return false;">退出</a></li>';
            h += '  </ul>';
            h += '</li>';
        }
        h += '</ul>';
        return h;
    }

    function bootstrap_html(navs, path, root) {
        if (navs.length == 0) return "";
        var h = '';
        if (root) {
            h += '<ul class="nav navbar-nav">';
            // 首页
            h += '  <li class="nav-item' + (path == "" ? " active" : "") + '">';
            h += '    <a class="nav-link" href="' + (path == "" ? "javascript:void(0);" : "/") + '">首页</a>';
            h += '  </li>';
        } else {
            h += '<ul class="dropdown-menu">';
        }

        for (var i = 0; i < navs.length; i++) {
            var nav = navs[i];
            if (!nav.IsDel) {
                var s_h = bootstrap_html(nav.Subs || [], path, false);
                var href = nav.LinkUrl ? (
                    (nav.LinkUrl.substring(0, 7) == "http://" || nav.LinkUrl.substring(0, 8) == "https://")
                        ? nav.LinkUrl : "/" + nav.LinkUrl + "/"
                ) : ("/" + nav.Path + "/");

                if (s_h == "") {
                    var active = (path == nav.Path);
                    h += '  <li class="nav-item' + (active ? " active" : "") + '">';
                    h += '    <a class="nav-link' + (active ? " active" : "") + '" href="' + href + '"' +
                         (nav.Blank ? ' target="_blank"' : '') + '>' + nav.Name + '</a>';
                    h += '  </li>';
                } else {
                    h += '  <li class="nav-item dropdown' + (active ? " active" : "") + '">';
                    h += '    <a class="nav-link dropdown-toggle" href="' + href + '"' +
                         (nav.Blank ? ' target="_blank"' : '') + '>' + nav.Name + '</a>';
                    h += s_h;
                    h += '  </li>';
                }
            }
        }
        h += "</ul>";
        return h;
    }
</script>
```

## 2.2 cms.title 标题/SEO模版

### 模板声明

```html
<uieip type="tmpl" value="cms.title"></uieip>
```

通常放在 `<head>` 中，自动生成页面标题和 SEO meta 标签。

### a) 自动生成标题（推荐）

不指定任何参数时，根据当前导航路径自动生成：
- **首页**（`path=""`）：使用站点信息的 `Title`/`Keywords`/`Description`
- **非首页**：使用导航项中的 `PTitle`/`PKeywords`/`PDescribe`（导航末节点）

```html
<head>
    <uieip type="tmpl" value="cms.title"></uieip>
</head>
```

### b) 手动指定标题/SEO

```html
<uieip type="tmpl" value="cms.title" title="404" keywords="" description=""></uieip>
```

**参数说明：**
| 参数 | 必需 | 说明 |
|------|------|------|
| title | 否 | 页面标题，指定后不再从导航自动获取 |
| keywords | 否 | 页面关键词 |
| description | 否 | 页面描述 |

### c) data 数据

data 数据同 [cms.nav](#21-cmsnav-导航信息) 的 data 格式。

参数数据获取参数为 `cms.nav`：
```javascript
var a = request.data("cms.nav");
```

### d) 管理员编辑按钮

PC 端管理员登录后，`cms.title` 会在页面右上角自动注入"模板编辑"按钮（`cms_page_edit()` 函数），用于在线编辑页面模板。移动端不会注入此按钮。

### e) 添加 js 时的行为

```html
<uieip type="tmpl" value="cms.title" js="myTitleFunc"></uieip>
```

当指定 `js` 参数时，只加载 data 数据到 `vm.Datas` 中，不自动生成 HTML，由 js 渲染函数处理。

## 2.3 cms.datalist 数据列表

获取数据库数据，默认为分页。

### 1) 分页模式

`isPage` 不为 `"false"` 时（即默认或显式 `isPage="true"`），按分页查询。

```html
<uieip id="div_list" type="tmpl" value="cms.datalist"
       dbname="db2" tbname="ab_test_m"
       isPage="true" pageno="1" pagesize="5"
       where="" order="sid"></uieip>
```

或（省略 isPage，默认分页）：
```html
<uieip id="div_list" type="tmpl" value="cms.datalist"
       dbname="db2" tbname="ab_test_m"
       pageno="1" pagesize="5" where="" order="sid"></uieip>
```

**参数说明：**
| 参数 | 必需 | 默认值 | 说明 |
|------|------|--------|------|
| dbname | 是 | — | 数据库名称 |
| tbname | 是 | — | 表名 |
| pageno | 否 | 1 | 起始页码 |
| pagesize | 否 | 10 | 每页条数 |
| where | 否 | "" | SQL WHERE 条件（不含 WHERE 关键字） |
| order | 否 | "modifytime desc" | 排序字段，系统会自动追加 `,modifytime desc` |
| isPage | 否 | "true" | 是否分页，设为 `"false"` 不分页 |
| js | 否 | "" | 服务端渲染函数名 |
| id | 否 | "cms.datalist" | 数据存储 key 名，可通过 `request.data("id值")` 获取 |

**分页 data 数据格式：**
```json
{
    "name": "index",
    "path": "news",
    "pageno": 1,
    "pagesize": 5,
    "pagecount": 2,
    "recordcount": 6,
    "rows": [{
        "sid": "5f055bb2-...",
        "tid": "axCKP0-ya",
        "title": "333333",
        "subtitle": "qweqweqwe",
        "summary": "345345345345",
        "body": "{\"html\":\"<p>...</p>\"}",
        "time": "2023-03-16 16:00:00",
        "img": null,
        "keywords": "eeee",
        "author": "qw",
        "createtime": "2023-03-09 18:37:08",
        "modifytime": "2023-04-04 19:28:38"
    }, {}, {}, {}, {}]
}
```

**分页 URL 规则：**
- `pageno==1`：URL 为 `news/`
- `pageno>1`：URL 为 `news/page{pageno}.html`，如 `news/page2.html`

### 2) 不分页模式

```html
<uieip id="div_list" type="tmpl" value="cms.datalist"
       dbname="db2" tbname="ab_test_m"
       isPage="false" where="" order="sid"></uieip>
```

**不分页 data 数据格式：**
```json
{
    "name": "index",
    "path": "news",
    "rows": [{}, {}, {}]
}
```

### 3) 数据获取

模板 id 存在时，参数数据获取参数为 id；模板 id 不存在时，参数数据获取参数为 `cms.datalist`。

```javascript

// 或
```

### 4) js 渲染函数

当模板声明了 `js="函数名"` 时，服务端执行该函数生成列表 HTML。

**示例：列表页 datalist 渲染**

取自 [webvue/cms/list.html](file:///d:/Spring/yuanqi.go-vue/webvue/cms/list.html)：

```html
<uieip id="div_list" type="tmpl" value="cms.datalist"
       dbname="yqbase" tbname="cms_news"
       pageno="1" pagesize="12" where="" order="time desc"
       js="datalist_js"></uieip>
<script runat="server">
    function datalist_js(data) {
        // data 参数包含：
        //   data.rows         — 数据行数组
        //   data.path         — 当前路径
        //   data.pageno       — 当前页码（仅分页模式）
        //   data.pagecount    — 总页数（仅分页模式）
        //   data.recordcount  — 总记录数（仅分页模式）
        //   data.name         — 当前页面名称

        var t_url = "/" + data.path + "/";
        var h_ = `<div class="list-group">`;

        for (var i = 0; i < data.rows.length; i++) {
            h_ += `   <a href="` + data.rows[i].tid + `.html" class="list-group-item">`;

            if (data.rows[i].img) {
                var img = JSON.parse(data.rows[i].img);
                var img_url = (img.sto_type == 1 ? "!" : "@") + img.sto_name + "_" + img.sid;
                h_ += '      <div class="media">';
                h_ += '        <div class="media-left"><img src="' + img_url + '"></div>';
                h_ += '        <div class="media-body">';
                h_ += '          <h4 class="media-heading">' + data.rows[i].title + '</h4>';
                h_ += '        </div>';
                h_ += '      </div>';
            } else {
                h_ += '      <div class="media-body">';
                h_ += '        <h4 class="media-heading">' + data.rows[i].title + '</h4>';
                h_ += '      </div>';
            }
            h_ += `   </a>`;
        }
        h_ += `</div>`;

        // 分页导航
        if (data.pagecount > 1) {
            h_ += `<ul class="pagination">`;
            if (data.pageno > 1) {
                var firsturl = t_url;
                var prevurl = data.pageno > 2 ? t_url + "page" + (data.pageno - 1) + ".html" : t_url;
                h_ += `<li><a href="` + firsturl + `">首页</a></li>`;
                h_ += `<li><a href="` + prevurl + `">上一页</a></li>`;
            } else {
                h_ += `<li class="disabled"><a href="javascript:void(0);">首页</a></li>`;
                h_ += `<li class="disabled"><a href="javascript:void(0);">上一页</a></li>`;
            }
            if (data.pageno < data.pagecount) {
                h_ += `<li><a href="page` + (data.pageno + 1) + `.html">下一页</a></li>`;
                h_ += `<li><a href="page` + data.pagecount + `.html">末页</a></li>`;
            } else {
                h_ += `<li class="disabled"><a href="javascript:void(0);">下一页</a></li>`;
                h_ += `<li class="disabled"><a href="javascript:void(0);">末页</a></li>`;
            }
            h_ += `<li class="disabled"><a href="javascript:void(0);">` + data.pageno + `/` + data.pagecount + `</a></li>`;
            h_ += `</ul>`;
        }

        return h_;
    }
</script>
```

## 2.4 cms.datarow 单条数据

### 模板声明

```html
<uieip id="div_row" type="tmpl" value="cms.datarow"
       dbname="db2" tbname="ab_test_m"
       seek="sid='{id}'" order="time desc"
       js="datarow_js"></uieip>
```

**参数说明：**
| 参数 | 必需 | 说明 |
|------|------|------|
| dbname | 是 | 数据库名称 |
| tbname | 是 | 表名 |
| seek | 否 | SQL WHERE 条件（不含 WHERE 关键字），支持 `{id}` 占位符 |
| order | 否 | 排序字段，当包含 `"time"` 时自动查询 `prev`/`next` 上下条 |
| js | 否 | 服务端渲染函数名 |
| id | 否 | 数据存储 key 名，可通过 `request.data("id值")` 获取 |
| current | 否 | 当前页面主数据，用于页面统计 |



### `{id}` 占位符规则

当 `seek` 参数包含 `{id}` 时，系统按以下优先级替换：
1. **导航 Tid**：当前导航路径末节点的 `Tid` 字段值
2. **页面名称**：当前 URL 的文件名（不含 `.html`，且不为 `"index"`）

例如：
- 导航项 Tid 为 `"axCKP0-ya"`，则 `seek="tid='{id}'"` → `seek="tid='axCKP0-ya'"`
- 无导航 Tid，URL 为 `/news/hello.html`，则 `seek="tid='{id}'"` → `seek="tid='hello'"`

### data 数据格式

```json
{
    "name": "fll9tno5u",
    "path": "news",
    "row": {
        "sid": "aef8ae5d-...",
        "tid": "fll9tno5u",
        "title": "联系我们",
        "subtitle": "联系我们",
        "summary": "联系我们",
        "body": "{\"html\":\"<h5>地址：北京市朝阳区...</h5>\"}",
        "time": "2023-03-15 16:00:00",
        "img": null,
        "keywords": "联系我们",
        "createtime": "2023-03-09 18:56:13",
        "modifytime": "2023-03-15 18:24:17"
    },
    "prev": {
        "sid": "a38115d3-...",
        "tid": "4-ojp0Ay9",
        "title": "555555",
        "time": "2023-03-14 16:00:00",
        "...": "..."
    },
    "next": {
        "sid": "34bbb494-...",
        "tid": "VGTO6mWaH",
        "title": "6666666",
        "time": "2023-03-15 16:00:00",
        "...": "..."
    }
}
```

### prev / next 上下条逻辑

当 `order` 参数包含 `"time"` 且查询到数据时，自动查询 prev（上一条）和 next（下一条）：
- **prev**：`time >= 当前记录时间` 且 `sid != 当前sid`，按 time 升序取第 1 条
- **next**：`time <= 当前记录时间` 且 `sid != 当前sid`，按 time 降序取第 1 条

### 数据获取

模板 id 存在时，参数数据获取参数为 id；模板 id 不存在时，参数数据获取参数为 `cms.datarow`。

```javascript
var a = request.data("div_row");
// 或
var b = request.data("cms.datarow");
```

### js 渲染函数

**示例 1：文章详情页（含上/下条导航）**

取自 [webvue/cms/page.html](file:///d:/Spring/yuanqi.go-vue/webvue/cms/page.html)：

```html
<uieip id="div_row" type="tmpl" value="cms.datarow"
       dbname="yqbase" tbname="cms_news"
       seek="tid='{id}'" order="time desc"
       js="datarow_js"></uieip>
<script runat="server">
    function datarow_js(data) {
        // data 包含：
        //   data.row         — 当前记录对象
        //   data.prev        — 上一条记录（可选）
        //   data.next        — 下一条记录（可选）
        //   data.path        — 当前路径
        //   data.name        — 当前页面名称

        if (data.row) {
            var h_ = '<div class="article jumbotron">';

            if (data.prev) {
                h_ += '   <a href="' + data.prev.tid + '.html">前一条：' + data.prev.title + '</a>';
            }
            if (data.next) {
                h_ += '   <a href="' + data.next.tid + '.html" class="pull-right">下一条：' + data.next.title + '</a>';
            }
            h_ += ' </div>';
            h_ += '</div>';
            return h_;
        } else {
            return "";
        }
    }
</script>
```

# 三、站点内部函数

以下函数为 `svr/cms` 包提供的 Go 内部函数，在服务端脚本中间接使用。

## 3.1 路径解析

请求 URL 会自动解析为以下数据：
- **`path`**：URL 路径部分（如 `news`、`product/detail`）
- **`name`**：文件名（不含 `.html`，如 `index`、`page2`）
- **`page`**：当文件名以 `page` 开头时，解析出页码（如 `page2` → 2）

## 3.2 移动端判断

系统自动根据 User-Agent、VIA、Accept、WAP Profile 等请求头判断是否为移动端访问，用于选择不同的模板文件（PC 端用 `ListUrl`/`ShowUrl`，移动端用 `ListUrl1`/`ShowUrl1`）。

## 3.3 模板文件解析

通过 `GetModelFile()` 函数根据文件名和移动端标识，结合导航配置查找对应的模板文件或外部 URL：
- **首页**：使用站点配置的 `IndexUrl`（PC）或 `IndexUrl1`（移动端）
- **列表页**（文件名以 `page` 开头）：使用导航项的 `ListUrl`/`ListUrl1`
- **详情页**：使用导航项的 `ShowUrl`/`ShowUrl1`
- **404 页面**：使用 `404.html`（PC）或 `404_1.html`（移动端）
- **外部链接**：如果配置的 URL 以 `http://` 或 `https://` 开头则直接跳转
