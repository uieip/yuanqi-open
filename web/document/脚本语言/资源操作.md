# 资源操作（resource）
# 一、文件函数
##1.1 ujson：获取ujson数据
```javascript
var res=resource.ujson(filename);
```
- filename：ujson文件路径

返回数据（示例）
```json
{
   "error":0,
   "data":{}
}
```

##1.2 file：获取文件内容信息
```javascript
var res=resource.file(filename);
```
- filename：文件路径

返回数据（示例）
```json
{
   "error":0,
   "text":"文件内容字符串"
}
```

# 二、操作消息函数
##2.1 actionMsgToString：操作消息转换为字符串
```javascript
var res=resource.actionMsgToString(pass, content);
```
- pass：密码字符串
- content：内容字符串

返回数据（示例）
```json
{
   "error":0,
   "info":"success",
   "value":"转换后的消息字符串"
}
```

##2.2 actionMsgByString：从字符串解析ActionMsg
```javascript
var res=resource.actionMsgByString(msg);
```
- msg：消息字符串

返回数据（示例）
```json
{
   "error":0,
   "info":"success",
   "pass":"解析出的密码",
   "content":"解析出的内容"
}
```

# 三、RSA函数
##3.1 rsaKeyPEM：生成RSA密钥对PEM格式
```javascript
var res=resource.rsaKeyPEM(bits);
```
- bits：密钥位数，支持1024、2048、4096

返回数据（示例）
```json
{
   "error":0,
   "info":"",
   "privateKey":"-----BEGIN RSA PRIVATE KEY-----\n...",
   "publicKey":"-----BEGIN PUBLIC KEY-----\n..."
}
```

##3.2 rsaKeyCsharpXML：生成RSA密钥对C# XML格式
```javascript
var res=resource.rsaKeyCsharpXML(bits);
```
- bits：密钥位数，支持1024、2048、4096

返回数据（示例）
```json
{
   "error":0,
   "info":"",
   "privateKey":"<RSAKeyValue><Modulus>...</Modulus>...</RSAKeyValue>",
   "publicKey":"<RSAKeyValue><Modulus>...</Modulus>...</RSAKeyValue>"
}
```

##3.3 rsaPublicKeyFromCsharpXML：C# XML公钥转PEM公钥
```javascript
var res=resource.rsaPublicKeyFromCsharpXML(xmlPublicKey);
```
- xmlPublicKey：C# XML格式的公钥字符串

返回数据（示例）
```json
{
   "error":0,
   "info":"",
   "value":"-----BEGIN PUBLIC KEY-----\n..."
}
```

##3.4 rsaPublicKeyToCsharpXML：PEM公钥转C# XML格式
```javascript
var res=resource.rsaPublicKeyToCsharpXML(pemPublicKey);
```
- pemPublicKey：PEM格式的公钥字符串

返回数据（示例）
```json
{
   "error":0,
   "info":"",
   "value":"<RSAKeyValue><Modulus>...</Modulus>...</RSAKeyValue>"
}
```

##3.5 rsaPrivateKeyFromCsharpXML：C# XML私钥转PEM私钥

```javascript
var res=resource.rsaPrivateKeyFromCsharpXML(xmlPrivateKey);
```


# 五、js函数
## 5.1 timeToISOString：将时间戳转换为ISO格式字符串
```javascript
var res=resource.timeToISOString(new Date());
```
返回示例：2023-12-31T23:59:59.999Z 或 null

## 5.2 domain2ip：将域名转换为IP地址
```javascript
var res=resource.domain2ip("www.baidu.com");
```
返回数据（示例）
```json
{
   "error":0,
   "info":"",
   "value":"ip地址字符串"
}
```
