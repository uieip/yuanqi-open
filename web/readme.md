# 远齐低代码开发平台（uieip）

*当前版本：v1.0*

## 目标

- 支持服务端跨平台部署系统，可以部署在Linux、Windows server、OS X Server。
- 支持主流数据库SQLite、Postgresql、MySQL，以及国产数据库openGauss、GaussDB、OceanBase、TiDB等。
- 系统既可以支持嵌入物联网设备服务开发，又能够作为管理支撑平台系统。
- 系统全部采用开源或自研架构进行开发，非第三方架构之上的封装，自主、国产。
- 建立社区，共建生态系统。

\*已开发数据库：SQLite、Postgresql（存储过程模板已开发）、KingbaseES（国产，金仓数据库）

## 编程语言及框架

- 服务端语言：Golang
- 脚本语言：JavaScript（ECMAScript 5.1）
- WEB框架：自研Vue（基于Vue3 + TypeScript + ElementPlus）

-## 核心引擎

本平台主要核心引擎包括：数据引擎、表单引擎、权限引擎、流程引擎、高级宏语言等。

### 数据引擎

数据引擎，即建模引擎。基于模型驱动，平台内置功能强大的建模引擎，能够快速创建应用程序。通过实体、数据结构、枚举等构建低代码数据模型。可视化定义数据之间的关联关系，平台自动生成数据库表和通用接口。

### 表单引擎

基于模板创建页面或在空白页面上通过拖、拉、拽组件的方式完成页面搭建。平台提供标准化组件，以及组件扩展能力，可维护自有组件库。

### 权限引擎

系统构建数据对象描述、菜单描述、组织描述、角色描述，能够对UI入口、数据、业务操作进行权限控制。

### 流程引擎

涵盖了流程设计、流程运行、管理维护、统计分析与流程优化等各类工具，能够快速部署、有效监控并持续优化业务流程。
（流程设计器已完成；流程引擎已开发，待完善）

### 高级宏语言（脚本语言）

基于高级宏语言设计，使用可视化设计开发图形界面，具备灵活的拓展性，不仅能满足企业的基本软件开发需求，而且具备成长属性。

### AI集成
- 集成AI模型，如Deepseek、火山引擎等云平台的AI模型，也可以自定义AI模型。
- 业务数据集成，能够将业务数据与AI模型进行交互，实现智能决策、智能推荐等功能。

### 其它
- 支持多语言，包括中文、英文等。
